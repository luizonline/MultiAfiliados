# MultiAfiliados

Plataforma centralizada para organizar produtos de afiliados, gerar links de divulgação e preparar publicações para canais de promoção.

## Escopo inicial
- Catálogo Mercado Livre e Shopee.
- Cadastro de produtos e identificadores de achadinhos.
- Busca, templates e compartilhamento via WhatsApp.
- Backup local e preparação para Supabase.

## Estado
Fundação inicial em desenvolvimento. Integrações com marketplaces, banco centralizado e envio automatizado ainda exigem configuração e validação técnica.

## Segurança
Nunca versionar tokens ou credenciais. Manter segredos somente no backend/Secrets. Respeitar os termos e permissões dos provedores.

Consulte `docs/SETUP.md` e `docs/ROADMAP.md`.
